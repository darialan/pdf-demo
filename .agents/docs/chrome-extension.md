# Web Printer Chrome 插件：核心 PRD 与技术方案

> 适用版本：扩展 `0.1.3` / 库 `1.1.0` · 最后核对：2026-10-31 · 状态：首版已实现，本文为首版方案基线
>
> 早期标题写的是"待实施"；扩展产物已按本方案落地（见 `extension/dist/manifest.json`）。新增范围先改本文，再改代码。

以当前 Web Printer、四个 demo 和 PDF／PNG 输出链路为基础；不要求先改造现有网站。本文只定义首版核心范围。

## 1. 产品目标

让用户在正在浏览的网页上，选择内容、保留当前渲染样式、按指定尺寸分页，导出 PDF 或逐页图片。用户无需改页面代码，也无需接入 npm 包。

首版面向三类任务：后台长表格归档、长文章保存、复杂图文内容分享；页眉页脚是这些任务的输出配置。分页是核心，文件格式是最后一步的选择。

体验目标是支持范围内样式一致、文字行不被切断、受保护内容按规则分页。“任何网页都完美还原”不作为未经验证的承诺；跨域资源、虚拟列表等边界必须在导出前说明。

## 2. 核心流程与界面

**点击插件图标 → 选择网页内容 → 调整输出设置 → 查看分页 → 导出。**

采用 Chrome 侧边栏作为持续操作界面，不用点击网页就关闭的短暂 popup。首屏提供「选择区域」和「整个页面」；选择区域时网页显示不占布局空间的高亮框，点击确认，可选父级、重新选择，Esc 退出选择。

侧边栏按以下顺序组织，避免把状态、设置和操作堆成一排：

| 区域 | 核心内容 |
| --- | --- |
| 当前内容 | 区域摘要、重新选择；只展示必要信息，不暴露 DOM 路径 |
| 输出设置 | 默认 A4；纸张／图片比例预设、自定义尺寸、方向、边距；页眉文字、页脚文字、页码收进折叠项 |
| 分页预览 | 首先显示当前页，按需加载其他页；页数、警告和重试属于这里 |
| 底部操作 | 一个导出主按钮，沿用工作台的下拉格式选择：PDF／PNG 分页图片；任务进行中显示进度和「取消导出」 |

- 选择有效内容后自动准备预览；设置变化防抖更新。切换格式不重新计算分页。
- 提供「排除内容」：用户点选广告、按钮等元素，在输出快照中忽略，可撤销；源网页不被删除或隐藏。
- 「检查分页」为可选高级操作，展示 `atomic`、`splittable`、`ignore`、`page-break`；普通流程不要求理解这些术语。检查标记与预览各自显示成功／失败，一项失败不阻塞另一项。
- PNG 输出为一个 ZIP，内含连续命名的完整分页图片；PDF 输出一个文件。格式变化只改变主按钮文案和输出结果。
- 错误说明原因和下一步，例如「这张图片无法读取，请排除后重试」「内容已变化，请重新生成预览」。不把堆栈或内部错误直接展示给用户。

## 3. 首版范围

| 支持 | 暂不支持 |
| --- | --- |
| 普通 HTTP／HTTPS 网页的主文档、选定元素及其已加载内容 | Chrome 内部页、扩展商店等受限页面；跨域 iframe 内容 |
| 表格、文本、图片、公式、代码块；已有引擎规则 | 自动抓取未加载内容、自动滚动补齐虚拟列表、分页接口抓取 |
| 尺寸、边距、简单页眉页脚、页码、点选排除 | 任意拖动分页点、复杂页眉设计器、站点专属适配市场 |
| 本地 PDF 和 PNG ZIP 导出 | 账号、付费、云处理、历史文件同步、原生可搜索 PDF |

“整个页面”指主文档已存在的内容，不等于整个业务数据库。特殊渲染、跨域图片、Shadow DOM、嵌套滚动容器先做兼容探测；无法完整处理时明确提示，不静默导出缺失内容。超高 `atomic` 内容默认报错并提示换尺寸或调整保护规则。

## 4. 技术架构与复用

使用 **Manifest V3 + TypeScript + React 侧边栏 + Vite 独立构建**，插件放在 `extension/`，不依赖 CRA 网站启动。Chrome 最低版本设为 116，以使用用户操作触发的 `sidePanel.open()`。[Chrome Side Panel 文档](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)

```text
侧边栏（设置、缩略图、进度）
       ↕ 带任务标识的消息
Content Script（选区、排除、快照、分页、截图、输出）
       ↓
Web Printer 共享库 → 原有 PDF writer／PNG writer

Service Worker：图标入口、按需注入、标签页会话协调
```

| 模块 | 实现边界 |
| --- | --- |
| `extension/background` | 打开侧边栏、注入内容脚本、处理标签页生命周期；不执行 DOM 测量或长时间截图任务 |
| `extension/content` | 默认运行于 isolated world；维护元素引用及本次任务，挂载选择／检查图层；避免改动页面业务状态 |
| `extension/sidepanel` | 独立于站点样式；仅接收结构化状态和缩略图，不把网页 HTML 注入扩展页面 |
| `extension/shared` | 消息类型、错误码、设置校验、任务状态机；不包含 DOM 引用 |
| `src/lib` | 复用 `prepareLayout`、`paginate`、`outputDocument`、输出 writer；不复制一套插件分页算法 |

复用现有预览逻辑时，从 demo 中抽取最小公共会话接口：会话持有**同一份冻结快照、分页结果和版本号**，预览按页读取，导出调用既有 capture／writer。现有 `outputDocument()` 的便利调用保持兼容。新增的是会话复用和插件适配，不重写测量、分页或 PDF／PNG 算法。

这一步是必要改动：当前独立调用检查、预览和导出会各自准备布局；插件面对动态网页时，不能仅凭相同配置假定三次结果一致。

## 5. 一致性、任务与资源

- **固定坐标系**：先打开侧边栏，待页面尺寸稳定，再确认选区；记录根宽度，去掉克隆根的外部定位偏移，保留内部样式。截图与分页使用同一快照坐标。
- **检查与排除**：选择框、统计和检查图层不进入快照。排除导致重排后，以打印快照为分页依据；原页无法准确映射的切线不强行叠加，提示在预览查看。
- **会话失效**：选区脱离 DOM、相关内容变化、可用宽度变化或设置修改时标记预览过期；过期状态不允许直接导出。导出开始后冻结当前会话，后续源页面更新不改变该文件。
- **任务状态**：`idle → selecting → preparing → ready → exporting → success/error`；取消回到可操作状态。每个消息带 `sessionId + requestId + revision`，后台按真实 sender 校验标签页身份；旧任务回调不得覆盖新任务。
- **生命周期**：切换标签页隔离状态；刷新、导航、关闭标签页或面板断开时取消并清理。Service Worker 重启不丢失仍在内容脚本中的任务状态，可重新握手查询；不依赖它常驻。[生命周期文档](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)
- **内存**：沿用资源超时、最大页数、单页像素预算和逐页释放；缩略图按需生成并限制缓存。PNG ZIP 仍有累计压缩字节内存开销，达到预算明确终止。
- **传输与下载**：消息只传 JSON 状态、页信息和限尺寸缩略图；不传 DOM、Blob 或整个 PDF／ZIP。Chrome 消息使用 JSON 序列化；最终文件留在内容脚本侧，优先复用本地下载链路，并在首轮原型验证 Chrome 下载行为。[消息文档](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)
- **清理**：取消、失败和成功都释放快照、Canvas、对象 URL、监听器与选择图层；取消后不得启动下载，不保留半成品文件。

## 6. 权限与隐私

首版权限仅申请 `activeTab`、`scripting`、`sidePanel`、`storage`；用户点击后才注入，不申请全站常驻读取权限。`activeTab` 提供临时授权，不保证访问跨域子框架或资源。[activeTab 文档](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

网页正文、截图与导出文件只在本地处理；仅保存尺寸、格式等偏好，不保存网页内容。所有执行代码及依赖随扩展打包，不从 CDN 加载脚本；不申请额外网络权限来掩盖渲染器的跨域限制。[MV3 远程代码约束](https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code)

## 7. 实施顺序与发布门槛

1. **兼容原型**：先跑通真实 MV3 环境中的注入、选区、样式读取、快照、截图和 PDF／PNG 下载；验证严格 CSP、跨域资源失败、侧边栏重排。原型不通过，先解决适配问题，不先堆界面。
2. **核心闭环**：抽取共享会话，完成选择／排除、尺寸配置、预览、格式切换、进度和取消；再补简单页眉页脚和检查视图。
3. **生产验收**：自动化、真实站点人工验证、权限及隐私说明通过后，产出可加载扩展包和商店材料；商店审核通过才算上架完成。

| 验收项 | 必须通过 |
| --- | --- |
| 单测 | 会话失效、消息校验、陈旧结果隔离、取消及资源释放；既有分页和 writer 单测全部回归 |
| 扩展自动化 | Playwright 加载真实扩展：四个现有场景逐一验证选区、排除、尺寸、预览及 PDF／PNG 下载；不只测试侧边栏 HTML |
| 文件正确性 | 解析 PDF 页数；解压并解码 PNG；两种格式分页相同、文件非空、完整页尺寸正确、无文字行或正常高度表格行截断 |
| 样式与交互 | 固定字体和数据做关键页视觉回归；开启／关闭侧边栏后无重复偏移或裁切；键盘可完成选区退出、设置与导出 |
| 故障恢复 | 跨域图片失败、资源超时、超高保护块、重复点击、取消、导航、面板关闭和 Worker 重启均有明确结果，重试可用且无残留图层 |
| 真实性能 | 在固定测试机和四个固定样本记录首个预览、总导出耗时与内存基线；进度逐页更新、取消在当前不可中断截图／编码结束后生效，不在等待整份文件期间假死 |
| 真实网页 | 至少验证一个博客和一个已授权后台页面，并覆盖嵌套滚动／虚拟列表的限制提示；通过 demo 不等于任意网站兼容 |

首版完成的定义：用户安装插件后，能在支持的网页中独立完成“选内容 → 看分页 → 导出”全过程，失败可理解、可恢复；npm 包和现有 playground 的行为不回退。
