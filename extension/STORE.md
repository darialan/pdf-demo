# 商店材料草案

名称：Web Printer

简短说明：保留网页样式，按指定尺寸分页，导出 PDF 或逐页图片。

详细说明：在当前网页上选择文章、表格或图文内容，调整页面尺寸和边距，查看分页效果，导出 PDF 或包含逐页 PNG 的 ZIP 文件。可点选排除广告、按钮等内容，设置简单页眉页脚和页码。内容在本地处理，不上传网页或导出文件。

权限说明见 PRIVACY.md。首版只读取已加载的主文档，不自动抓取未加载或虚拟列表中的数据，不绕过跨域资源限制，不支持 Chrome 内部页面。
