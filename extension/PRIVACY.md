# Web Printer 隐私说明

Web Printer 在您点击插件图标后，临时读取当前网页中您选择的内容，用于本地分页、预览和导出。网页正文、图片、截图及导出文件不会上传至 Web Printer 服务器，也不发送给第三方分析服务。

扩展仅保存页面尺寸、边距、页眉页脚文字、页码及输出格式等偏好到本机 Chrome 存储。您可以恢复默认设置；移除扩展会清除扩展保存的偏好。

权限用途：`activeTab` 临时读取您主动选择的当前标签页；`scripting` 注入本地分页脚本；`sidePanel` 显示操作侧边栏；`storage` 保存本机偏好。扩展不申请全站常驻访问权限，不收集浏览历史，不提供云端文件同步。

原网页自身可能继续加载它自己的字体、图片等资源；这些请求仍受网站及浏览器的访问控制。Web Printer 不将您的文件发送到外部服务以绕过跨域限制。
