# 第二阶段：Landing Page

当前实现为产品事实来源；旧方案只用于阶段顺序。主转化为安装 NPM 包，工作台提供验证入口。使用 copywriting 与 design-taste-frontend。

## 定位与证据

- 长网页按实际文字行和表格行分页 → 长文章、45 行表格的真实分页测试。
- 还原已渲染页面的布局与样式 → 原样式 TorchOptics 图文、公式和代码 demo；受 html2canvas 支持范围与跨域资源限制。
- 同一分页链路输出 PDF 或 PNG → outputDocument 的格式 writer；四场景实际文件下载验证。
- 尺寸、边距、页眉页脚与页码可配置 → 输出设置、品牌差旅单场景。
- 浏览器本地运行，框架无关 → DOM 输入 API；React/Vue 示例均在客户端调用。

页面不承诺任意 CSS 无条件完整还原，不使用虚构付费客户、评价、节省时间或转化率。PDF 为光栅正文，PNG 打包 ZIP。

## 本产品素材清单

真实 HTML 输入、文字行测量、表格行保护、atomic/splittable/ignore、原文公式/代码/图片、品牌重复页眉页脚、尺寸预设、PDF/PNG 两种输出、同一分页结果、浏览器本地处理、NPM 安装命令、四场景可运行工作台。

## 页面论证顺序

1. 长网页分好每一页 → 真实引擎响应尺寸切换；安装命令可直接复制。
2. 样式、分页规则与输出尺寸分别解决什么 → 具体能力与可验证行为。
3. 四种内容各自如何分页 → 当前 demo 的四张真实工作台截图与对应入口。
4. 如何接入 → 一个 DOM 输入、同一 API 选择 PDF/PNG；JS/React/Vue 可复制示例。
5. 使用边界与安装入口 → FAQ 回答格式、资源、超高内容、许可等接入疑问。

copywriting 诊断 B：已有清楚的“保留现有页面、处理分页”立场；保留该立场，纠正 PDF 独占定位和过时签章主场景。

## 视觉方向

design-taste-frontend：product-performs，seed 1931159189；保留现有绿色与字体。产品的连续 HTML 成为一组真实分页，尺寸切换即是唯一主要演示交互。采用真实截图，无需库存照片。原方向中的氛围照片、固定滚动叙事不适合短接入页面，使用真实预览和普通阅读顺序。品牌更名留在第三阶段。

## 验收

主 CTA 安装 NPM 包；安装命令可复制，失败可手动复制。四场景链接选中正确 tab。首屏尺寸切换调用实际分页管线，取消和卸载清理快照。代码示例使用真实 API。桌面/平板/手机、亮暗主题、键盘操作与减少动画偏好可用。最终检查与截图结果在实施后补充。

## 视觉复核

两轮看图与修正：首轮缩短移动端问答标题；将被裁切的源文档副本放进无脚本 sandbox iframe，隔离纸张文档与营销页面的样式、标题及焦点。第二轮检查 1440/768/390 的全部 7 张截图，0 FAIL / 2 WARN。

保留的警告：字号计数同时涵盖代码、品牌与真实界面控件；正文、标题和次级文字仍有明确层级。页面用可操作的真实分页替代视频，不增加无关素材或自动播放。静态 lint 的编号警告对应实际门店编号，不是营销章节编号。

最终看图评分：设计 7.5 / 可用性 8 / 创意 7 / 内容 8，加权 7.6。最强的是可直接操作的分页与明确安装入口；四场景截图在手机上仅用于识别场景，细节由完整工作台承接。所有图片均为本仓库真实工作台截图，无外部图库或虚构客户素材。
