# Chrome 扩展实施与验收记录

日期：2026-10-31。扩展版本：0.1.0。范围以 [PRD 与技术方案](../chrome-extension-prd-and-design.md) 为准。

**放行状态：功能及隔离扩展环境验收已完成；日常 Chrome 安装和真实后台最终复核仍受外部条件阻塞，不能标记为全部交付完成或已上架。**

## 已实现

- MV3 插件、图标入口、独立 React 侧边栏，采用最小的 `activeTab / scripting / sidePanel / storage` 权限。
- 网页区域／整页选择、选父级、Esc 退出、点选排除和撤销；不删除或隐藏源网页内容。
- 纸张／图片预设、自定义尺寸、方向、单位、四边边距、简单页眉页脚及页码；本机偏好保存。
- 同一份冻结快照与分页结果用于按页预览、PDF 和 PNG ZIP；预览缓存只保留三页。
- 独立的检查标记与预览错误处理，格式选择、进度、取消、过期提醒、重试、标签页隔离及刷新重连。
- Worker 只负责入口和注入；暂停／重启后不丢失内容脚本中的会话。旧 revision 请求不会覆盖新状态。
- 页面／选区失效、关闭连接、取消和失败均清理快照、画布与监听器。PNG 累计编码数据设 128 MiB 预算。

## 页面与真实环境

采用 `design-taste-frontend` 的 Achromatic ledger 方向，seed 1882235665，沿用现有品牌字标、系统字体和绿色标识。界面首先回答“所选内容将怎样分页并保存”；主要操作始终在底部，设置和只读状态分区呈现。

- 320 / 390 / 640 px 渲染检查：0 FAIL、0 WARN。初轮发现整页误用 fragment 标记及小字号，已修复；第二轮调整窄侧栏边距与滚动边界。
- 已逐宽度查看实际截图，并在应用内浏览器检查首屏、内部滚动、预览下半部与固定导出栏。应用内查看的是真实扩展 DOM 的只读快照；交互验收在真实扩展环境完成。
- 主观复核：层级、可读性、操作路径各 8/10；菜单阴影只用于浮层。实际 Chrome 安装与授权入口未评分。
- 真实博客：在作者公开文章页面完成选区、预览与实际 PDF 下载。修复了将 `overflow:hidden` 的有意裁剪误判为未展开滚动的问题，以及源内容更新后下载成功状态丢失的问题。
- 本地后台 `127.0.0.1:4000/insights`：持续显示加载骨架，未把它算作真实业务内容验收通过。显式 live 测试将该情况标为跳过；后续须在页面可用时重跑。

## 性能基线

Apple M1 Pro，本机 Playwright Chromium，A4 默认设置；PNG 导出耗时不含之前的准备阶段。记录位于 `extension-artifacts/benchmarks/`。

| 场景 | 页数 | 准备 | PNG 导出 | JS 堆：开始 → 结束 |
| --- | ---: | ---: | ---: | ---: |
| 长表格 | 2 | 约 0.32 s | 约 0.67 s | 约 23 → 43 MiB |
| 长文章 | 4 | 约 0.10 s | 约 0.66 s | 约 26 → 30 MiB |
| 复杂图文 | 12 | 约 1.00 s | 约 23.78 s | 约 29 → 82 MiB |
| 页眉页脚 | 2 | 约 0.13 s | 约 0.60 s | 约 22 → 31 MiB |

JS 堆读数是浏览器近似值，不代表进程、解码图片或 GPU 峰值；单页像素预算、累计 PNG 字节预算及晚到画布释放另有代码和单测约束。复杂图文导出仍是主要耗时项，保留逐页进度与可取消行为，不宣称瞬时导出。
